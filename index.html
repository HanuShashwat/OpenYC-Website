# Seed Round Timing

## Principle
The optimal time to raise is when you still have runway
and can negotiate from strength, not desperation.

## Verbatim Quotes
- "The best time to raise money is when you don't need it."
  — Paul Graham, Founder of YC

## Fallback Behavior
Return the 3 closest skills. Never invent YC quotes.
Why it exists

Vague advice is risky. Verbatim advice is usable.

Ask an AI agent a startup question and you often get confident advice with no source, no speaker, and no way to check it. OpenYC Skills fixes that by distilling Y Combinator's public content — Library essays and YouTube videos — into skill files where every quote is verbatim, attributed to a named speaker, and checked by an automated validation pipeline.

The core promises

Three promises, kept by design

Everything on this site traces back to one idea: verified YC advice your AI agent can actually use.

Zero cost for consumers

Download static files from GitHub. No API keys, no database, no embedding models, no Python.

Exact quote fidelity

Every quote attributed to a YC speaker is verbatim from the original transcript or essay. No paraphrasing in attribution blocks — enforced by automated validation.

Composable skills

Each skill covers one narrow micro-topic and links to related skills using pre-computed cosine similarity — math, not guesswork.

How it works

From YC content to a card your agent can follow

Think of each skill file as a recipe card for an AI agent. The card says what the advice is, who said it (with the exact quote), when to use it, what questions to ask the founder, and which other cards are related. The agent reads the card and follows it.

  1. Ingest YC content

    A contributor downloads a YC Library essay or a YouTube transcript (English captions only).

  2. Distill into skill files

    LLMs extract actionable advice and verbatim quotes, then cluster corroborating sources into one skill file per micro-topic.

  3. Verify every quote

    Each quote is fuzzy-matched against its source and schema-checked. Anything that fails cannot be published.

  4. Agents load the files

    Skills ship as static files in three formats — MCP, OpenAI function calling, and Hermes. No server, no runtime.

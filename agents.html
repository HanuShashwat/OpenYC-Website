OpenYC Skills for AI Agents

Give your agent verified startup advice from Y Combinator's public content — no server, no API keys, no Python. Just static files you load into your agent.

What you get

These are the only files you care about as a consumer. Everything else in the repo — src/, config/, data/raw/, data/chunks/ — is for contributors who generate skills.

File / directory What it contains Use it when
skills/{category}/{skill_id}.md The skill content — principle, verbatim quotes, application instructions, edge cases You want the full knowledge content
specs/mcp/{skill_id}.json MCP (Model Context Protocol) spec Your agent uses Claude Code or MCP-compatible frameworks
specs/openai/{skill_id}.json OpenAI function-calling spec Your agent uses GPT or the OpenAI API
specs/hermes/{skill_id}.txt Plain-text system prompt fragment Your agent runs on a local model (Ollama, llama.cpp)
skills-index.json Machine-readable index of all skills Looking up skills by ID, category, or tag
data/similarity_matrix.json Pre-computed similarity scores between skills Fuzzy or semantic skill search

Published incrementally

Skills are added manually by contributors with no fixed schedule. The skills/ directory currently contains no published files, so the example paths and skill IDs on this page are illustrative — check skills-index.json in the repo for the current state.

Three ways to get the files

1. Clone the repository

git clone https://github.com/HanuShashwat/openyc-skills.git

Then access files at openyc-skills/skills/, openyc-skills/specs/, and so on.

2. Download a release bundle

Check the Releases page for skills-bundle.zip, which contains all skills, specs, and index files.

3. Fetch individual files via raw URLs

Fetch any file directly over HTTPS — useful for agents that load skills on demand without cloning the full repo.

https://raw.githubusercontent.com/HanuShashwat/openyc-skills/main/skills/fundraising/yc-fundraising-seed-round-timing.md
https://raw.githubusercontent.com/HanuShashwat/openyc-skills/main/specs/mcp/yc-fundraising-seed-round-timing.json
https://raw.githubusercontent.com/HanuShashwat/openyc-skills/main/skills-index.json

The two skill paths above are illustrative — they exist once skills are published.

Which format should I use?

Format File Used by Key characteristics
MCP specs/mcp/{skill_id}.json Claude Code, MCP-compatible frameworks Tool definition: name, description, inputSchema, handler.path, tags, fallback
OpenAI specs/openai/{skill_id}.json GPT, OpenAI API function calling {"type":"function","function":{...}} plus custom metadata (skill_file, category, tags, fallback)
Hermes specs/hermes/{skill_id}.txt Ollama, llama.cpp, local models Plain text with [SKILL: ...] / [END SKILL] delimiters, injected into system prompts

Pick the format that matches your framework:

  • Claude Code → MCP
  • GPT / OpenAI API → OpenAI
  • Local models (Ollama, llama.cpp) → Hermes
  • Custom framework → read the skill .md files directly

How agents find skills

When your agent receives a question, it resolves a signal to the right skill or skills:

Signal Example Returns
Exact ID lookup yc-fundraising-seed-round-timing That skill's file at skills/fundraising/yc-fundraising-seed-round-timing.md
Category filter (/) /fundraising All skills in the skills/fundraising/ directory
Subcategory filter /fundraising/seed-round Skills matching yc-fundraising-seed-round-*
Tag filter (%) %seed All skills with seed in their tags
Multi-tag AND %seed,runway Skills tagged with both seed and runway
Fuzzy search (no prefix) fundraising timing The 3 most similar skills via the similarity matrix

skills-index.json provides the by_id, by_tag, and by_category lookup tables. data/similarity_matrix.json holds pre-computed cosine similarity scores — no machine-learning libraries needed at runtime.

Fallback behavior — the most important rule

Identical in every spec

  • If no skill matches the user's question, return the 3 closest skills.
  • The agent may use its own general knowledge, clearly labeled as general advice.
  • The agent must never invent YC quotes (invent_quotes: false).

Wrong vs. right (illustrative example from the consumption guide)

Wrong: As Paul Graham says, "You should always raise money when you have traction." (If this exact quote doesn't appear in a skill file, the agent invented it.)

Right: Paul Graham has spoken about the importance of timing in fundraising. For his exact advice, see the skill "yc-fundraising-seed-round-timing".

Integration examples

The examples below are copied from the consumption guide. The skill IDs they reference are illustrative until skills are published.

Look up a skill by ID

import json

with open("skills-index.json") as f:
    index = json.load(f)

skill_info = index["by_id"].get("yc-fundraising-seed-round-timing")
if skill_info:
    print(f"Found: {skill_info['name']} at {skill_info['path']}")
    # Load the skill file
    with open(skill_info["path"]) as f:
        skill_content = f.read()

OpenAI function calling

import json
import openai

# 1. Load the spec file
with open("specs/openai/yc-fundraising-seed-round-timing.json") as f:
    tool_spec = json.load(f)

# 2. Load the skill content
with open(tool_spec["metadata"]["skill_file"]) as f:
    skill_content = f.read()

# 3. Add the tool to your OpenAI API call
response = openai.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "system", "content": f"You are a startup advisor. Use this knowledge:\n\n{skill_content}"},
        {"role": "user", "content": "I have 4 months of runway. Should I raise now?"}
    ],
    tools=[tool_spec],  # Pass the spec as a tool definition
    tool_choice="auto"
)

Hermes specs for local models

import os

# Load all Hermes skill specs
skills_text = ""
hermes_dir = "specs/hermes/"
for filename in os.listdir(hermes_dir):
    if filename.endswith(".txt"):
        with open(os.path.join(hermes_dir, filename)) as f:
            skills_text += f.read() + "\n\n"

# Use as system prompt
system_prompt = f"""You are a startup advisor powered by Y Combinator knowledge.
Use the following skills to answer founder questions:

{skills_text}

IMPORTANT RULES:
- Only use quotes marked as VERBATIM QUOTES. Never invent new YC quotes.
- Follow the AGENT PROTOCOL for each matching skill.
- If no skill matches, say so and use your general knowledge clearly labeled as such.
"""

# Now pass system_prompt to your local model
